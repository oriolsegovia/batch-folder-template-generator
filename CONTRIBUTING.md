# Contributing

Contributions are welcome if they preserve the project's **local-first and privacy-safe** design.

Before opening a pull request:

1. Do not include real personal, administrative or production data.
2. Do not commit PDFs, DOCX files, production templates, executables or logs.
3. Use fictitious numeric IDs in examples and tests.
4. Keep network access optional or absent; the default application should remain fully local.
5. Preserve safe handling of existing folders: never overwrite user files silently.
6. Test input validation and folder creation behavior before submitting changes.

For security-sensitive findings, follow the guidance in [SECURITY.md](SECURITY.md).
